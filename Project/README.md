# Weather Dashboard

Phase 1 proposal for a React Native weather app. Users will search for a city, view current weather and a seven day forecast, and open a day for details.

## Phase 1 files

- `Weather_Dashboard_Proposal.docx` - proposal and screen plan
- `wireframes/01_city_search.png` - city search sketch
- `wireframes/02_forecast_list.png` - forecast sketch
- `wireframes/03_day_details.png` - day details sketch

## Planned app setup

1. Create an Expo React Native project.
2. Install Axios, React Navigation, and Expo Vector Icons.
3. Run `npx expo start --tunnel` to open it in Expo Go on a phone.

The app itself is planned for the next phase. These setup steps are not runnable in this Phase 1 folder yet.

## API

- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) for city search
- [Open-Meteo Forecast API](https://open-meteo.com/en/docs) for current and daily weather

The free noncommercial API does not require a key. The app will display Open-Meteo attribution. Weather data will be requested live; no local database or saved forecast data is planned.

## Planned screen flow

City Search -> Forecast -> Day Details
